# Data Model: Semantic Memory

## Entities

### Experience

Represents a past interaction stored persistently.

- `id`: Integer (Primary Key, Auto-increment)
- `task_text`: Text (The original user request)
- `task_type`: Text (Optional classification, default to "general")
- `response_text`: Text (The agent's final response)
- `status`: Text (Indicates execution success or error, e.g., "success", "error")
- `metadata_json`: Text (JSON string for optional metadata)
- `created_at`: Timestamp (When the experience was created)

### Experience Vectors

Stores the semantic embedding associated with an experience.

- `experience_id`: Integer (Foreign Key referencing Experience.id)
- `embedding`: Float Vector (Generated by `nomic-embed-text`)

*Note*: Using `sqlite-vec`, this is typically a virtual table that links to the primary `experiences` table.

## Database Schema

```sql
CREATE TABLE IF NOT EXISTS experiences (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_text TEXT NOT NULL,
    task_type TEXT DEFAULT 'general',
    response_text TEXT NOT NULL,
    status TEXT NOT NULL,
    metadata_json TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE VIRTUAL TABLE IF NOT EXISTS experience_vectors USING vec0(
    experience_id INTEGER PRIMARY KEY,
    embedding float[768] -- Assuming nomic-embed-text generates 768-d vectors. Must verify dimension dynamically or structurally.
);
```
