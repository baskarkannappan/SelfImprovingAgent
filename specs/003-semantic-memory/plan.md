# Implementation Plan: Semantic Memory

**Branch**: `003-semantic-memory` | **Date**: 2026-09-12 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-semantic-memory/spec.md`

## Summary

Implement a persistent semantic memory layer for the Phase 1 Google ADK agent. We will use SQLite and `sqlite-vec` to persistently store past tasks and their vector embeddings (generated by `nomic-embed-text` via Ollama). The agent will query this memory before answering new prompts to build relevant context. We will also implement a read-only Streamlit developer visualization to inspect this database.

## Technical Context

**Language/Version**: Python 3.11+

**Primary Dependencies**: 
- `google-adk`
- `sqlite-vec`
- `streamlit`
- `pydantic`
- `python-dotenv`

**Storage**: SQLite (`data/agent.db`) with `sqlite-vec` extension for vector operations.

**Testing**: `pytest`

**Target Platform**: Local Windows execution (Google ADK local POC)

**Project Type**: Agent extension / Data storage / Streamlit Web App

**Performance Goals**: Local dev responsiveness (fast retrieval from small local vector DB).

**Constraints**: Local Ollama only for embeddings. Must not overwrite or modify existing memory. Must gracefully fall back if memory/embeddings are unavailable.

**Scale/Scope**: Local POC scale, handful of memory entries.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **I. Code Quality**: The memory functionality will be isolated in a dedicated `self_improving_agent/memory` package to keep the core agent module clean.
- **II. Testing Standards**: Pytest tests will be added for the memory store, vector retrieval, and empty memory behavior.
- **III. User Experience Consistency**: The main UI remains ADK Web. The Streamlit UI will use standard Streamlit patterns for developer inspection.
- **IV. Performance Requirements**: `sqlite-vec` runs natively in SQLite, ensuring high performance for semantic searches without massive memory overhead.

All constitution gates PASS.
