# Agent Interface Contract

The root agent `self_improving_agent` does not expose a programmatic REST API or CLI interface.

## Supported Interaction Protocol

Interaction is strictly governed by the **Google ADK 2** framework via the `adk web` development server.

1. **Discovery**: The agent must be exported or registered within the `self_improving_agent` module such that the ADK framework discovers it dynamically.
2. **Conversation Input**: Natural language strings provided by the user in the ADK Web UI.
3. **Conversation Output**: Natural language strings generated by the Llama 3.2 model, streamed or returned to the ADK Web UI.
4. **Error Handling**: Hard failures (e.g., LLM unreachable) must be caught and returned as conversational error messages to the UI, not raw stack traces.
